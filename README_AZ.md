# Marakana Mobile Native v58

## v58 — Hesab Satışı: oyun/müştəri seçimi + tarix formatı

- Yeni hesab satışı və hesab düzəlişi ekranında **Oyunun adı** sahəsinə klik etdikdə WordPress bazasındakı bütün oyun adları açılır.
- Açılan siyahıda yazaraq oyun axtarmaq, siyahıdan seçmək və tapılmayan adı əl ilə yazıb istifadə etmək mümkündür.
- **Ad soyad** sahəsinə klik etdikdə bütün müştərilər açılır; ad və ya telefonla axtarmaq, seçmək və əl ilə yeni ad yazmaq mümkündür.
- Siyahıdan müştəri seçiləndə onun telefon nömrəsi avtomatik doldurulur.
- Satış tarixi mobil UI-da `DD-MM-YYYY` formatında göstərilir və daxil edilir; WordPress API-yə göndərilərkən avtomatik `YYYY-MM-DD` formatına çevrilir.
- Hesab kartlarında satış tarixi də `DD-MM-YYYY` kimi görünür.
- v57-dəki Satılanlar/Satılmayanlar ikonları, v56 Yeni müştəri, v55 1 saniyə basılı saxla menyusu və əvvəlki funksiyalar saxlanılıb.

Build:
- `versionCode 58`
- `versionName 3.4.35-native-v58`
- Release APK: `MarakanaMobile-v58-release.apk`
