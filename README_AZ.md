## v138 — Hesab Satışı: yeni hesabda qiymət yoxdur

- `Hesab Satışı > Yeni hesab yarat` formasında artıq Qiymət xanası göstərilmir.
- Yeni hesab yaratmaq üçün oyun seçimi və e-mail əvvəlki kimi məcburidir.
- Hesab növü və hər növə ayrıca Məxfi kod axını saxlanılıb.
- Yeni hesab WordPress schema-sı ilə uyğunluq üçün stokda `price=0` ilə yaradılır; istifadəçi qiymət daxil etmir.
- `Sat` və `İcarə ver` formalarında Satış qiyməti / İcarə qiyməti sahələri əvvəlki kimi qalır və əməliyyat zamanı təyin edilir.
- Hesab düzəlişində mövcud Qiymət sahəsi saxlanılıb; yalnız yeni hesab yaratma ekranından çıxarılıb.
- Online direct WordPress API, Gateway və Local IP davranışına toxunulmayıb.
